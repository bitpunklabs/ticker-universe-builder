# Global v0.10.0 implementation validation — 2026-10-18

## Result

Global composition and strict TradingView TXT support are implemented. Three additional design
reviews followed the original three-round study. The skill entrypoint, maintained contract,
CLI, tests, worked input and plugin metadata agree on version 0.10.0.

The complete suite passed: **433 tests and 898 subtests**, 10.61 seconds in the recorded run.
The Global/package subset passed 64 tests. Ruff passed, the skill-creator validator passed using
its development-only PyYAML dependency, and `git diff --check` passed. Runtime remains Python
standard library only. This is local validation, not a public registry release.

## Behavior covered

- Separately pinned coverage contracts; native source qualification and file hashes; portable
  copied sources; exact selected-row recomputation; complete source-theme disposition ledger.
- Economic/ADR/share-class identity collisions and legal-ID duplicates; prohibited source-row
  substitution; company versus index/basket coverage duties; mandatory named inclusions/exclusions.
- ETF assets, fees, spreads, inception, full normalized holdings, dated evidence and thirty raw
  notional observations; recomputed turnover and holdings overlap; duplicate benchmark wrappers.
- Lost/shrunken duties, stale/future facts, boolean metrics, unsafe identifiers, missing holdings,
  low turnover, invalid coexistence and weak fund-floor overrides fail publication.
- Strict exchange prefixes, commas, ticker uniqueness, safe/nonempty sections, exact membership
  across all three views and the 1,000-token ceiling including headers. CRLF cannot be silently
  normalized away during file validation.
- Atomic output collision handling; moving an output bundle; post-publication source/member/
  contract/path/TXT mutation; packaged runtime imports and Global command availability.

Synthetic test data stays in tests. It is not promoted into a researched market universe.

## Dated end-to-end pilot

The [worked Global example](../../examples/global/README.md) was run with a separately researched
SOXX catalog. The result has **22 symbols: 16 equities, five indices and one ETF**, spanning
CN/US/JP/HK/KR, eight thematic groups and thirteen explicit duties. Its main TXT has 22 tokens;
the theme view has 30 and the market view 27. All three contain exactly the same symbols.

Company evidence and measurements inherit the native examples' actual dates. Newly inspected
index pages support TSE:TOPIX, HSI:HSI and KRX:KOSPI identities. SOXX uses issuer assets, fees,
median spread and all thirty equity holdings dated 2026-10-15/16, with fee observation explicitly
dated 2026-10-18. Nasdaq daily close/share volume yields thirty completed sessions from
2026-09-04 through 2026-10-16; the last raw close matches the independently read issuer price.
Mean close-times-shares notional is approximately USD 4.068 billion. This is a turnover proxy,
not exchange-reported consolidated notional or a return-quality finding.

Yahoo history acquisition failed; Stooq returned browser-verification HTML. Neither became
evidence. The Nasdaq initial date parameter was rejected, then repaired to ISO dates and
returned the actual history. Acquisition metadata and raw hashes are retained locally; those
failed transports do not count as facts.

The pilot passed independent CLI validation after relocation and through the updated installed
skill. A replay from preserved inputs succeeded. Source JSON, original expected contract and
all exported TXT were rechecked. The approved personal r6's six authoritative universes,
eight exports and three original lists retain their prior hashes and native qualification.

## Review boundaries

This pilot is not the planned approximately 200–280-symbol worldwide production universe. It
does not complete the international leader census, all candidate ETF comparisons or country
coverage. DIA remains a requirement of the user's eventual full design; the smaller pilot tests
a distinct bounded contract. Syntax/source validation does not prove TradingView account import,
feed subscriptions, live quote availability or UI behavior. Those tests were not performed.

English report names/reasons use the existing authored source translations. HTML row counts and
relative links are checked locally; no new visual/browser acceptance is asserted.

## Reproduce

```bash
python -m pytest tests -q -o addopts=''
ruff check .
python examples/global/build_example.py --output temp/NEW_GLOBAL_PILOT
python scripts/universe.py validate-global \
  temp/NEW_GLOBAL_PILOT/bundle/global-2026-10-18.json \
  --contract temp/NEW_GLOBAL_PILOT/inputs/coverage-contract.json
python scripts/universe.py check-watchlist \
  temp/NEW_GLOBAL_PILOT/bundle/global-2026-10-18.txt --ticker-only
```

The repository-only replay has 21 symbols without SOXX. The local review pilot adds its
researched catalog with `--fund-catalog`. The complete native examples can be rebuilt offline
before the pilot if their outputs are absent. Preserve source dates when replaying.
