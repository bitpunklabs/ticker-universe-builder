# 0.2.0 — Scoring and measurement disclosures

Historical design/implementation record, 2026-09-22. These weighted-selection diagnostics
belong to archived replay, not the current [coverage selector](../../references/coverage-plan.md).
Nine audit findings included two already implemented; the remaining seven produced four changes.

## Changes and implementation corrections

| Finding | Shipped change |
|---|---|
| Missing metrics inflated weighted scores | Divide by full bucket-field weight; retain scored_on present/total and measurement population |
| Theme floor cost was invisible | Report floor_share; warn above 75%, revised from the proposed 50% |
| Floored bucket shares lost fractional seats to core | Largest-remainder allocation with deterministic ties |
| Required members distorted theme drift | Remove required seats from both held and expected before lowering the drift floor |
| Selection had no noise-sensitivity measurement | Deterministic independent ±1% draws per asset/field, two extra selection passes |
| Evaluation missed redundant member pairs | Report pairwise correlations, without an automatic exclusion gate |

The old present-field denominator scored liquidity-only 0.95 above complete
0.90/0.85/0.80/0.75 at 0.85. Full denominator avoids rewarding missing research without inventing
replacement metrics. In the old examples 5% of eligible candidates lacked independence; fixing
this bug changed no example membership because those candidates already ranked below winners.

The theme floor consumed 38–66% of Light budgets, median 56%; Brazil used 23/35 seats.
The proposed 50% warning flagged ten of fourteen valid tables, so implementation disclosed the
quantity and moved the warning to 75%. Largest remainder fixed nine fractional entitlements;
Brazil tactical 1.75 became two rather than one. Drift originally used held >=5 and >2.5×expected;
required benchmarks were outside apportionment and therefore needed removal from both sides.

Uniform ±1% perturbation would rescale linear scores without reordering. Shipped draws use a
digest of (draw, asset_id, field), independently reproducible. Historical Light stability across
fourteen markets was 0.90–1.00, median 0.97: UK lost five of fifty seats, KR/FR none.
Build-time stability requires the full bench; stored validation cannot recompute it.
